  • Terrain Registerer startup is now 3× faster (jobified + Burst data extraction)
  • Optimized terrain detail chunk streaming
  • Added profiler markers to ensure all BRGIR code is wrapped

1.3.1 — 2026-07-17

  • Added Force Disable Shadows to BRG Prototype Group — useful for a "Grass Shadows" graphics option

Major Update 1.3.0 — 2026-07-16

Added

  • Draw Command Filtering — draw commands are now only submitted for prototypes that exist within a chunk visible to the sub-view. Reduces draw calls and improves CPU performance on large scenes, especially with multiple shadow-casting lights.
  • Improved shadow culling tightness and efficiency for slightly better GPU performance
  • New editor-only debugging toggles

Fixed

  • Terrain tree chunk bounds were way oversized
  • Occlusion culling in VR now properly uses a per-eye depth pyramid
  • Fixed occlusion culling in HDRP when using hardware dynamic resolution
  • Fixed incorrect occlusion culling at low resolution

1.2.1 — 2026-07-13

  • Added option to skip BRGIR rendering for specific cameras
  • Added tree chopper and planter demo
  • Fixed PC VR rendering on Vulkan when the Mobile Patcher is applied

1.2.0 — 2026-07-08

  • Switched pool size to hold 16 instances instead of 64. If you changed Max Pools Per Chunk or Initial Num Pools, you'll need to set them again after the update to be 4× as high as your previous values.
  • Optimized GPU uploads
  • Faster legacy light probe sampling

Major Update 1.1.0 — 2026-06-20

Features

  • Added shadow occlusion culling to improve shadow rendering performance
  • Added the ability to render terrain "Texture Grass" details with BRGIR
  • Optimized Point Light shadow culling
  • Distance Density scaling is now multiplied by global density scaling for a correct combined result

Bug Fixes

  • Fixed rendering on Adreno mobile GPUs
  • Fixed occlusion culling breaking when changing resolution scale or using upscalers on both URP and HDRP
  • Fixed occlusion culling in URP compatibility mode
  • Fixed broken Point Light shadow rendering
  • Fixed instances disappearing when spawning and moving them on the same frame
  • Fixed incorrect detail streaming on rectangular terrains
  • Optimized undo/redo speed for scenes using terrains
  • Fixed Legacy Light Probes not working properly in player builds

Debugging

  • Improved "Runtime Stats" window to show more useful information
  • Added debug option to draw bounding spheres
