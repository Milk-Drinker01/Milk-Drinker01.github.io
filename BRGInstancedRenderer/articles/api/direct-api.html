Direct API

In most cases, you should use a BRGRegistrationTracker or Custom Registerer instead of calling these methods directly. They handle prototype reference counting, chunk tracking, overflow management, and automatic cleanup. Calling the raw API means you are responsible for all of that yourself — failing to unregister prototypes or free chunks will leak GPU memory.

The direct API is available on the BRGRenderer singleton via BRGRenderer.Instance. These are the same methods that BRGRegistrationTracker calls internally.

Singleton

Member Description
static BRGRenderer Instance Get or create the singleton. Auto-initializes on first access.
static bool HasInstance Check if the singleton exists without creating it.
bool IsInitialized Whether the system is initialized and ready.

Prototype Registration

Method Description
int RegisterRenderSignatureFromPrefab(GameObject prefab) Register a render signature from a prefab. Returns the prototype index, or -1 on failure. Increments the reference count if already registered.
int[] RegisterRenderSignaturesFromPrefab(GameObject prefab) Register multiple signatures from a prefab that produces more than one (e.g. multi-renderer prefabs). Returns the array of prototype indices.
int RegisterRenderSignature(RenderSignature signature) Register a custom render signature. Deduplicates by asset identity hash + config hash. Returns the prototype index.
bool UnregisterRenderSignature(int protoIndex) Decrement the reference count for a prototype. Returns true if the count reached zero. Zero-refcount prototypes are automatically purged after a grace period (default 30s, configurable via Prototype Idle Grace Period). If the prototype is re-registered before the grace period expires, it is reused without any GPU work.
int PurgeUnusedPrototypes() Immediately remove all prototypes with a reference count of zero, bypassing the grace period. Returns the number purged.
RenderSignature GetPrototype(int protoIndex) Get the render signature for a prototype index.
int GetPrototypeRefCount(int protoIndex) Get the current reference count.

Chunk Management

Method Description
int AllocateChunk() Allocate a new chunk. Returns the chunk ID.
void WriteChunk(int chunkId, NativeArray<InstanceData> instances, Bounds bounds, float cullDistance = 0f, float instanceCullDistance = float.MaxValue) Write instances to a chunk. Bounds should tightly enclose all instances. cullDistance is a per-chunk distance cutoff (0 = unlimited). instanceCullDistance applies during GPU culling per-instance.
void FreeChunk(int chunkId) Free a chunk and return its pools to the free list.
bool IsChunkValid(int chunkId, int generation) ABA-safe liveness check. Use against a ChunkLink's stored generation to detect stale handles.
int GetChunkGeneration(int chunkId) Get the current generation counter for a chunk slot.
void RecalculateChunkBounds(int chunkId, Bounds newBounds) Update chunk culling bounds. Use after removals have made the original bounds too loose.
void SetChunkEnabled(int chunkId, bool enabled) Enable or disable a chunk for rendering.
int GetChunkInstanceCount(int chunkId) Get the number of instances in a chunk.
int GetChunkPoolCount(int chunkId) Get the number of pools currently used by a chunk.
int GetChunkPoolIndex(int chunkId, int poolLocalIdx) Get the global pool index for a chunk's local pool slot.

Instance Addition & Removal

Method Description
int AddInstance(int chunkId, InstanceData instance) Add a single instance. Returns the global slot index, or -1 if the chunk is full.
int AppendInstances(int chunkId, NativeArray<InstanceData> instances, int srcOffset, int count, NativeArray<int> outSlotIndices) Add multiple instances. Returns the number actually placed. Slot indices are written to outSlotIndices.
void RemoveInstance(int chunkId, int globalSlotIndex) Remove an instance by slot index. Chunk bounds are not automatically recalculated.
void SetInstanceEnabled(int globalSlotIndex, bool enabled) Enable or disable an instance. Disabled instances are invisible to culling but keep their slot and pool allocation.

Instance Modification

All modification methods take a global slot index and stage the change for GPU upload.

Method Description
void SetInstancePosition(int globalSlotIndex, float3 position) Set position only.
void SetInstanceRotation(int globalSlotIndex, quaternion rotation) Set rotation only.
void SetInstanceScale(int globalSlotIndex, float3 scale) Set scale only.
void MoveAndRotateInstance(int globalSlotIndex, float3 position, quaternion rotation) Set position and rotation.
void MoveInstance(int globalSlotIndex, float3 position, quaternion rotation, float3 scale) Set full TRS. Light probes are not re-sampled automatically.
void SetInstanceColor(int globalSlotIndex, Color32 color) Set per-instance color. Requires Enable Per-Instance Color on the Config.
void SampleInstanceLightProbe(int globalSlotIndex, float3 position) Re-sample light probes at a position. Call manually after moving an instance if using legacy light probes.

Buffer & Memory

Method Description
void CompactBuffers() Compact GPU buffers to reduce memory waste. Leaves ~25% headroom. Causes a small hitch — call during loading screens or pauses.
void ShiftInstances(Vector3 offset) Shift all instance positions and chunk bounds by an offset. For floating origin systems. You are responsible for shifting GameObjects, terrain, and cameras separately.
void FlushStagedUploads() Force all staged GPU uploads to execute immediately. Normally called automatically before culling.
long AllocatedBufferMemory Total allocated GPU buffer memory in bytes.

Lifecycle Example

using Unity.Collections;
using Unity.Mathematics;
using UnityEngine;

namespace BRGInstancedRenderer
{
    public class DirectAPIExample : MonoBehaviour
    {
        [SerializeField] GameObject _prefab;

        int _protoIndex = -1;
        int _chunkId = -1;

        void OnEnable()
        {
            var brg = BRGRenderer.Instance;

            // 1. Register prototype
            _protoIndex = brg.RegisterRenderSignatureFromPrefab(_prefab);
            if (_protoIndex < 0) return;

            // 2. Allocate chunk
            _chunkId = brg.AllocateChunk();

            // 3. Build instance data
            var instances = new NativeArray<InstanceData>(100, Allocator.TempJob);
            for (int i = 0; i < 100; i++)
            {
                instances[i] = new InstanceData
                {
                    position = new float3(i * 2f, 0f, 0f),
                    rotation = quaternion.identity,
                    scale = new float3(1f),
                    prototypeIndex = _protoIndex,
                    color = new Color32(255, 255, 255, 255)
                };
            }

            // 4. Write to chunk
            var bounds = new Bounds(Vector3.zero, new Vector3(200f, 10f, 10f));
            brg.WriteChunk(_chunkId, instances, bounds);
            instances.Dispose();
        }

        void OnDisable()
        {
            if (!BRGRenderer.HasInstance) return;
            var brg = BRGRenderer.Instance;

            // You must clean up manually
            if (_chunkId >= 0)
            {
                brg.FreeChunk(_chunkId);
                _chunkId = -1;
            }

            if (_protoIndex >= 0)
            {
                brg.UnregisterRenderSignature(_protoIndex);
                _protoIndex = -1;
            }
        }
    }
}

Compare this with the equivalent BRGRegistrationTracker or Custom Registerer version, which handle chunk freeing, overflow, and prototype unregistration automatically.
