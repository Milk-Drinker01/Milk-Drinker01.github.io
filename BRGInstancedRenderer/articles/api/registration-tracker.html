BRGRegistrationTracker

Before reading this page, make sure you've read System Overview to understand how prototypes, render signatures, chunks, and pools work together.

BRGRegistrationTracker is the resource tracking layer that both BRGRegisterer and the built-in registerers use internally. It manages prototype reference counting, chunk tracking with automatic overflow, and full cleanup on shutdown — without requiring a GameObject.

Use BRGRegistrationTracker directly when you need to manage BRG instances from a non-MonoBehaviour context (ECS systems, static managers, network callbacks, etc.). For MonoBehaviour-based registration, use Custom Registerer (BRGRegisterer) instead, which wraps a tracker with automatic OnEnable/OnDisable lifecycle.

Creating a Tracker

using Unity.Collections;
using Unity.Mathematics;
using UnityEngine;

namespace BRGInstancedRenderer
{
    public class MyManager
    {
        BRGRegistrationTracker _tracker;
        int _protoIndex = -1;
        ChunkLink _chunk;

        public void Start(GameObject prefab)
        {
            _tracker = new BRGRegistrationTracker("MyManager");

            // Connect to BRGRenderer singleton
            if (!_tracker.Initialize()) return;

            // 1. Register render signature
            _protoIndex = _tracker.RegisterRenderSignatureFromPrefab(prefab);
            if (_protoIndex < 0) return;

            // 2. Allocate a chunk
            _chunk = _tracker.AllocChunk();
            if (!_chunk.IsValid) return;

            // 3. Build instance data
            var instances = new NativeArray<InstanceData>(100, Allocator.TempJob);
            for (int i = 0; i < 100; i++)
            {
                instances[i] = new InstanceData
                {
                    position = new float3(i * 2f, 0f, 0f),
                    rotation = quaternion.identity,
                    scale = new float3(1f),
                    prototypeIndex = _protoIndex,
                    color = new Color32(255, 255, 255, 255)
                };
            }

            // 4. Write to chunk
            var bounds = new Bounds(Vector3.zero, new Vector3(200f, 10f, 10f));
            _tracker.WriteChunk(_chunk, instances, bounds);
            instances.Dispose();
        }

        public void Stop()
        {
            // Frees all chunks, unregisters all prototypes, disconnects from BRGRenderer
            _tracker?.Shutdown();
        }
    }
}

Lifecycle

Method Description
new BRGRegistrationTracker(string name) Create a tracker. The name is used in log messages.
bool Initialize() Connect to BRGRenderer.Instance. Returns false if the singleton is unavailable.
void Shutdown() Free all tracked chunks, unregister all prototypes, and disconnect. Safe to call multiple times.
Property Type Description
BRGSystem BRGRenderer The singleton reference. Set after Initialize(), null after Shutdown().
IsRegistered bool true while the tracker is initialized.
Name string Display name for log messages.

Callbacks

You can set callbacks for initialization and shutdown, which is how BRGRegisterer hooks in its OnInitialize / OnShutdown methods:

var tracker = new BRGRegistrationTracker("MyTracker");
tracker.InitializeCallback = () => { /* register protos, alloc chunks, etc. */ };
tracker.ShutdownCallback = () => { /* clean up local state only */ };
tracker.Initialize(); // calls InitializeCallback after connecting

If InitializeCallback throws, the tracker automatically calls ShutdownCallback and shuts down to prevent partial initialization.

Structs

InstanceData

Per-instance data for registration and updates.

Field Type Description
position float3 World-space position.
rotation quaternion World-space rotation.
scale float3 Local scale.
prototypeIndex int Global prototype index returned by RegisterRenderSignatureFromPrefab or RegisterRenderSignature.
color Color32 Per-instance color tint. Requires Enable Per-Instance Color on the Config.

PrototypeData

The asset definition — meshes, materials, LODs, and other data extracted from a prefab. This is the "what does it look like" data. Accessed via RenderSignature.asset.

Field Type Description
sourcePrefab GameObject Original prefab (used for identity comparison).
mesh Mesh Base mesh (LOD 0).
materials Material[] Materials per submesh (LOD 0).
lodMeshes Mesh[] Additional LOD meshes (LOD 1+).
lodMaterials Material[][] Materials per LOD level.
lodScreenSizes float[] Screen relative heights for LOD transitions.
lodFadeTransitionWidths float[] Crossfade width per LOD level.
lodCastsShadows bool[] Whether each LOD casts shadows.
lodMotionVectorModes MotionVectorGenerationMode[] Per-LOD motion vector mode.
lodGroupSize float Reference size for LOD calculations.
fadeMode LODFadeMode Crossfade mode from LODGroup.
percentageFadeMask uint Bit N = LOD N uses percentage fade (SpeedTree).
speedTreeRendererID int Renderer instance ID for SpeedTree wind lookup.
usesMeshLod bool Unity 6.2+ Mesh LOD instead of separate meshes per level.

RenderSignature

The full registration unit — combines a PrototypeData asset with render behavior configuration. This is what you pass to RegisterRenderSignature or RegisterRenderSignatures when you need explicit control over render settings.

The same prefab can be registered multiple times with different render settings. Deduplication uses both sourcePrefab and a hash of the config fields, so two RenderSignatures with the same prefab but different shadow settings are treated as separate prototypes.

Field Type Default Description
asset PrototypeData — The mesh/material/LOD data.
motionVectorMode MotionVectorGenerationMode — Motion vector generation mode.
animateCrossFading bool — Whether to use animated crossfade.
maxShadowCascade int 4 Max shadow cascades.
minShadowLOD int 0 Minimum LOD for shadow mesh.
maxShadowDistance float 0 Max shadow distance, 0 = global.
maxShadowCrossfadeCascade int -99 Cascade-specific crossfade control.
lodFadeDuration float 0 Animated crossfade duration override.
enableGlobalDensityScaling bool false Enable runtime global density scaling.
enableDynamicDensity bool false Enable per-instance dynamic density.
dynamicDensityMode DynamicDensityMode ScreenSize ScreenSize or Distance.
densityStartScreenSize float 0.1 Screen size where thinning begins.
densityStartDistance float 50 Distance where thinning begins.
densityEndDistance float 150 Distance where thinning reaches minimum.
densityMinFraction float 0.3 Minimum density fraction.
densityFadeWidth float 0.05 Crossfade width for density transitions.
layer int 0 GameObject layer.
renderingLayerMask uint 0xffffffff URP/HDRP rendering layer mask.

Most users can simply call RegisterRenderSignatureFromPrefab(GameObject), which extracts a RenderSignature from the prefab automatically (including any BRG Prototype Extra Data settings). You can also call ExtractRenderSignature(GameObject) to get a RenderSignature without registering it, modify it, and then pass it to RegisterRenderSignature.

ChunkLink

Handle to an allocated BRG chunk. Tracked for automatic cleanup on shutdown.

Member Type Description
Id int Internal chunk identifier.
IsValid bool true if the chunk was successfully allocated.
Invalid static Sentinel value for an invalid chunk.

InstanceLink

Handle to a single instance within a chunk. Provides convenience methods for per-instance modification.

Method Description
SetColor(Color32) Set per-instance color.
SetPosition(float3) Set position only.
SetRotation(quaternion) Set rotation only.
SetScale(float3) Set scale only.
MoveAndRotate(float3, quaternion) Set position and rotation.
Move(float3, quaternion, float3) Set full TRS (position, rotation, scale).
SampleLightProbe(float3) Re-sample light probes at the given position.
SetEnabled(bool) Enable or disable this instance. Disabled instances are invisible to culling but keep their slot.
Remove() Remove this instance from its chunk.
Property Type Description
GlobalBRGSlotIndex int Global slot index in the instance buffer.
ChunkId int The chunk this instance belongs to (may be an overflow chunk).
IsValid bool true if the instance handle is valid.

Render Signature Registration

All registrations are tracked and automatically unregistered on Shutdown().

Method Description
RenderSignature ExtractRenderSignature(GameObject prefab) Extract a RenderSignature from a prefab without registering it.
int RegisterRenderSignatureFromPrefab(GameObject prefab) Register from a prefab. Returns the global prototype index, or -1 on failure.
int RegisterRenderSignature(RenderSignature signature) Register an explicit RenderSignature. Returns the global prototype index, or -1 on failure.
Dictionary<int,int> RegisterRenderSignatures(List<RenderSignature> signatures) Batch-register. Returns a local-to-global index remap.
void UnregisterRenderSignatures(Dictionary<int,int> remap) Manually unregister a batch before shutdown.

Chunk Management

All chunks are tracked and automatically freed on Shutdown().

Method Description
ChunkLink AllocChunk() Allocate a new chunk.
void WriteChunk(ChunkLink, NativeArray<InstanceData>, Bounds, ...) Write instances to a chunk. Automatically splits across overflow chunks if instance count exceeds MaxInstancesPerChunk. Overflow chunks share bounds with the primary chunk.
void ReleaseChunk(ChunkLink) Free a chunk and all its overflow chunks. Idempotent.
void RecalculateChunkBounds(ChunkLink, Bounds) Update chunk culling bounds.

Instance Management

Method Description
InstanceLink AddInstance(ChunkLink, InstanceData) Add a single instance. Tries the primary chunk, then overflow chunks, then allocates a new overflow if needed.
InstanceLink[] AddInstances(ChunkLink, NativeArray<InstanceData>, int) Add multiple instances with automatic overflow.
InstanceLink MoveInstanceToChunk(InstanceLink source, ChunkLink dest, InstanceData) Move an instance between chunks. Adds to destination first, then removes from source. Returns InstanceLink.Invalid if the destination is full.

Queries

Method Description
InstanceLink[] GetInstanceLinks(ChunkLink) Get handles for all instances (primary + overflow). Only available for chunks written with createInstanceHandles = true.
int[] GetInstanceSlots(ChunkLink) Get raw global slot indices for the primary chunk only.
int GetTotalChunkInstanceCount(ChunkLink) Total instance count including overflow chunks.
int GetOverflowChunkCount(ChunkLink) Number of overflow chunks.
void GetPerChunkInstanceCounts(ChunkLink, List<int>) Instance counts per sub-chunk: primary at index 0, then each overflow.

Instance Handle Callback

When writing chunks with createInstanceHandles = true, the handles may not be available immediately if a deferred GPU buffer resize is needed. Subscribe to InstanceHandlesReady to be notified when handles are ready:

tracker.InstanceHandlesReady += (chunkId) =>
{
    var links = tracker.GetInstanceLinks(myChunkLink);
    // cache or use links
};

Difference from BRGRegisterer

BRGRegisterer is a thin MonoBehaviour wrapper around BRGRegistrationTracker. It adds:

  • Automatic Initialize() on OnEnable, Shutdown() on OnDisable
  • Editor support via [ExecuteAlways] with deferred initialization
  • Abstract OnInitialize() / OnShutdown() hooks via the callback system
  • Protected method forwarding so subclasses don't touch the tracker directly

If your registration logic lives in a MonoBehaviour, use Custom Registerer. If it doesn't, use BRGRegistrationTracker directly.
