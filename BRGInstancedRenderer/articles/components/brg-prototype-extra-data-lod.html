Screen Size / LOD Overrides

Per-prototype LOD and screen-size settings on BRG Prototype Extra Data. These control LOD crossfade behavior and screen-size culling for individual prefab types.

For Mesh LOD configuration (Unity 6.2+), see BRG Mesh LOD Data.

Animated Crossfade Duration

When a LOD Group with animated crossfading is present on the prefab:

Property Type Default Description
Override Animated Crossfade Duration bool false Enables a per-prototype animated crossfade duration, overriding the global default on the Config.
Animated Crossfade Duration float 0.3s Time in seconds for animated LOD crossfade transitions for this prototype.

Screen Size Culling

Disabled when a LOD Group or Mesh LOD is active (use the LOD Group's culled level or Mesh LOD's min screen size instead).

Property Type Default Description
Min Screen Size float (0–5%) 0 Screen size percentage below which instances are culled. 0 = disabled (use LOD Group defaults). For LOD prototypes this overrides the last LOD's cull threshold if larger; for non-LOD prototypes it adds screen-size culling to something that would otherwise always render.
Fade Mode enum None How instances disappear at the cull boundary: None (instant pop).
Crossfade (stateless dither).
Animated Crossfade (time-based fade).
Fade Width float (0–1) 0 Width of the fade band for stateless crossfade mode.

When Fade Mode is set to Animated Crossfade, the Override Animated Crossfade Duration field appears here instead of the LOD Group section above.
