2D Setup

Pixel-Perfect Fog Of War fully supports 2D projects. The setup is the same as 3D with a few differences.

Enable 2D Mode

On the Fog Of War World component, enable the Is 2D? checkbox. In 2D mode the fog is calculated on the XY plane.

Use the 2D Revealer

Add the Fog Of War Revealer 2D component to your revealers (instead of the 3D revealer). The 2D revealer uses Unity's 2D physics raycasts against your 2D colliders. Set the Obstacle Mask to the layers that should block vision.

See Fog Of War Revealer 2D for the full property reference.

Built-In Pipeline Cameras

If you are on the Built-In render pipeline, add the FOW Image Effect component (not the Opaque variant) to your camera. See Render Pipeline Setup.

Everything Else Is the Same

Hiders, fog appearance, sampling modes, regrow, minimap, and optimization all work identically in 2D. Continue with:
