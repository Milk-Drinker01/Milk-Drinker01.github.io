Changelog

Big thanks to everyone for your continued support of Pixel-Perfect Fog Of War. Your reviews and feedback make it possible to keep shipping new features and performance updates!

3.4.0 — 2026-06-23

  • Reworked all Fog of War appearance shaders into a single shader
  • Added a Shader Stripper ScriptableObject to reduce shader variants
  • Added a Custom Appearance shader include, so you can easily write your own Fog of War shader
Important

Updating to 3.4 from an older version? Delete FogOfWar/Shaders/Resources and re-import to avoid shader import errors (the appearance shaders were merged into one).

3.0.0 — Major overhaul and optimization update

New Features / Content

  • Occlusion is now optional on revealers. Disabling occlusion allows for tens of thousands of revealers with minimal performance cost
  • Hiders can now be revealed by sampling Texture Storage fog
  • The inner-edge soften angle can now be configured per-revealer
  • The unobscured softening distance can now be configured per-revealer
  • New Fog Of War World update method: Start in Update, Finish in Late Update — gives the C# job for the first iteration longer to complete on its own
  • Made gradual reveal fade in/out separate options when using Fog Regrow / Memory
  • You can now set the global fog strength (FogOfWarWorld.SetFowEffectStrength())
  • New API to subscribe to when a revealer sees or loses sight of a hider
  • 2 new demo scenes:
    • Demo 08: 1,000 revealers + 1,000 hiders (large-scale RTS occlusion quality)
    • Demo 09: 10,000 revealers (no occlusion)

Inspector Cleanup

  • Categorized the revealer inspector
  • Renamed "Allow Bleeding" to "Add Slight Arc Leaking", and made it work with soft fog
  • Renamed hider sample options on the revealer for clarity

Optimizations

  • Complete rewrite of the shader logic for significantly optimized GPU performance
  • New Spatial Hash Grid sampling system — allows tens of thousands of revealers with minimal GPU impact
  • Hiders are significantly faster
  • Optimized 3D revealer projection math
  • Optimized GPU bandwidth — only changed revealer info is uploaded to the fog shader, and the total amount of data needed on the GPU is reduced
  • Optimized job scheduling for revealers
  • Optimized and cached more repeated revealer calculations
  • Significantly reduced the memory size of the fog texture

Bug Fixes

  • Fixed tooltips not showing on revealers
  • Fixed microscopic leaks that could occur when two sight segments are very close together
  • Fixed URP shaders in Unity 6.3
  • Fixed duplicate shader defines in partial hider shaders
