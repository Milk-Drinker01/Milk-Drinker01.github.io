Pixel-Perfect Fog Of War
Table of Contents

Components

Full reference for every component in Pixel-Perfect Fog Of War.

Fog Of War World

The central manager. One per scene — owns all global fog settings, drives revealer updates, and renders the fog.

Fog Of War Revealer 3D

Reveals fog around a GameObject using 3D physics raycasts for line of sight.

Fog Of War Revealer 2D

The 2D counterpart, using 2D physics raycasts.

Fog Of War Hider

Marks an object to be hidden when it falls outside of line of sight.

Hider Behaviors

Components that decide what happens when a hider is hidden or revealed (disable objects, disable renderers, toggle objects).

FOW Image Effect

Built-In render pipeline camera components that draw the fog.
