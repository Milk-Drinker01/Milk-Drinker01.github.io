Revealer Update Modes

You control when revealers calculate line of sight on the Fog Of War World component.

Revealer Update Mode

Mode Description
Every Frame Every revealer recalculates line of sight every frame. Most accurate, most expensive.
N Per Frame Revealers take turns. Only Max Num Revealers Per Frame recalculate each frame — fewer per frame means more performance. (Default.)
Controlled Elsewhere No revealer recalculates automatically. You drive updates yourself in code (see below).
Property Type Default Description
Max Num Revealers Per Frame int (min 1) 25 How many revealers recalculate per frame when using N Per Frame.

Update Method

Update Method controls where in the frame the fog work happens:

Method Description
Update Work happens in Update.
Late Update Work happens in LateUpdate. (Default.)
Start In Update, Finish In Late Update Line-of-sight jobs are kicked off in Update and completed in LateUpdate, giving the Burst jobs the maximum time to run before being forced to complete.
Tip

Start In Update, Finish In Late Update is often the best choice for performance, because it lets the multithreaded line-of-sight jobs run across the frame instead of blocking.

Driving Updates Manually

With Controlled Elsewhere, recalculate a revealer yourself:

revealer.ManualCalculateLineOfSight();

See the Revealer API.
