World Bounds

World bounds options on the Fog Of War World component. See World Bounds for a conceptual overview.

Property Type Default Description
World Bounds Bounds center (0,0,0), size (1,1,1) The rectangular extent of your world on the fog plane. Edit with the scene gizmo or numerically.
Use World Bounds bool false Renders everything outside the bounds as solid black.
World Bounds Soften Distance float 1 Softens the boundary edge of the black-out.
World Bounds Influence float 1 How strongly the black-out is applied.
Note

World Bounds are also required (independent of the Use World Bounds black-out feature) when using Minimap Generation or the Texture sampling mode.

You can update bounds at runtime with UpdateWorldBounds.
