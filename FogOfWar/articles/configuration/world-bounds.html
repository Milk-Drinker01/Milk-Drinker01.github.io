World Bounds

World bounds options on the Fog Of War World component. The black-out toggle lives under FOW Extra Rendering Options, and the bounds volume itself under the FOW Bounds section (shown when bounds are needed). See World Bounds for a conceptual overview. (Labels below match the inspector; the code field name is noted where it differs.)

Property Type Range Description
Darken Out-Of-World-Bounds Area? bool — Renders everything outside the bounds as solid black. Code: UseWorldBounds.
World Bounds Soften Distance float 0 → 5 Softens the boundary edge of the black-out. Code: WorldBoundsSoftenDistance.
World Bounds Influence float 0 → 1 How strongly the black-out is applied. Code: WorldBoundsInfluence.
Center Vector3 — Center of the bounds volume. Code: WorldBounds.center.
Extents Vector3 — Extents of the bounds volume. Edit with the scene gizmo or numerically. Code: WorldBounds.extents.
Note

The FOW Bounds section (Center / Extents) appears whenever bounds are required — when Darken Out-Of-World-Bounds Area? is on, when using Minimap Generation, or when Fog Sample Mode is Texture Storage. You can also drag the box gizmo in the Scene view.

You can update bounds at runtime with UpdateWorldBounds.
