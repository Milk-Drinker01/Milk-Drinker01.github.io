Regrow & Fading

Regrow and fading options on the Fog Of War World component. See Fog Regrow & Fading for a conceptual overview.

Important

These options require the Texture sampling mode.

Property Type Default Description
Use Regrow bool false Explored areas gradually return to fog after revealers leave.
Revealer Fade In bool false Newly revealed areas fade in over time instead of popping.
Revealer Fade In Speed float 0.5 Speed of the fade-in.
Revealer Fade Out bool false Areas a revealer leaves fade out over time.
Revealer Fade Out Speed float 0.5 Speed of the fade-out.
Initial Fog Exploration Value float 0 How explored the world is at startup (0 = fully fogged).
Max Fog Regrow Amount float 0.3 Caps how much fog can grow back, allowing partially-remembered areas.
