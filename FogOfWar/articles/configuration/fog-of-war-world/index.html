Fog Of War World

The Fog Of War World component holds every global fog setting. This section documents its properties, organized to match the component's custom inspector, top to bottom. For adding the component and the essential first-time settings, see Getting Started: Fog Of War World.

Inspector Sections

Rendering Options

FOW Rendering Options — the fog look in one place: General Rendering (fog type, fade, blend, dithering, distances), Fog Appearance (the Fog Shader look and its options), and Extra Rendering (pixelation, world-bounds darkening, invert, arc leaking).

Sampling Mode

FOW Sampling Mode — Pixel-Perfect vs Texture Storage, and texture-storage sampling options.

Texture Options

FOW Texture Options — fog texture resolution, hider sampling, async readback, and fog regrow/fading.

Bounds

FOW Bounds — the world bounds volume (center / extents).

Configuration & Optimizations

Update timing, spatial acceleration, and staged GPU uploads.

Utility Options

Buffer limits, 2D mode, and game-plane orientation.

Note

Labels throughout this section match the inspector exactly; the underlying code field name is noted where it differs (useful for the API).
