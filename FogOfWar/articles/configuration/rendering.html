Rendering

Core rendering options on the Fog Of War World component, under FOW Rendering Options > General Rendering Options. (Labels below match the inspector; the code field name is noted where it differs.)

Property Type Range Description
Fog Type enum Hard / Soft Hard fog has crisp edges; Soft fog blurs sight-segment edges into a gradient. See Hard & Soft Fog.
Soft Fog Fade Mode enum Linear / Exponential / Smooth / Smoother / Smooth Step (Soft only) Falloff curve for soft fog. Code: FogFade.
Fade Exponent float — (Soft + Exponential only) Curve power. Code: FogFadePower.
Revealer Combination Mode enum Maximum / Additive (Soft only) How overlapping revealers combine. Additive adds opacities; Maximum takes the strongest. Code: BlendType.
Revealer Extra Sight Distance float -1 → 1 Lets fog expand slightly past its actual vision radius to prevent Z-fighting. Use negative values to prevent unwanted bleeding (e.g. with pixelated or low-res texture fog). Code: SightExtraAmount.
Revealer Extra Sight Distance Softening float 0 → 1 (Soft only) Softens the extra sight distance edge. Code: EdgeSoftenDistance.
Max Fog Distance float 0 → 10000 The maximum distance from the camera at which fog is rendered.
Note

Use Dithering? and Dithering Size also live in this section (under Soft Fog Options), but are documented with the other stylization options in Appearance.
