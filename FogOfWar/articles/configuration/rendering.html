Rendering

Core rendering options on the Fog Of War World component.

Property Type Default Description
Fog Type enum (Hard / Soft) Soft Hard fog has crisp edges; Soft fog blurs sight-segment edges into a gradient. See Hard & Soft Fog.
Fog Fade enum Smoothstep Falloff curve used for soft fog: Linear, Exponential, Smooth, Smoother, or Smoothstep.
Fog Fade Power float 1 Curve power, used when Fog Fade is set to Exponential.
Blend Type enum (Max / Additive) Additive How overlapping revealers combine. Additive adds opacities; Max takes the strongest.
Sight Extra Amount float 0.01 Lets fog expand slightly past its actual vision radius to prevent Z-fighting. Use negative values to prevent unwanted bleeding (e.g. with pixelated fog or low-resolution texture fog).
Edge Soften Distance float 0.1 Controls softening for the revealer's extra sight distance.
Max Fog Distance float 10000 The maximum distance from the camera at which fog is rendered.
