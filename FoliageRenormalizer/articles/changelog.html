Changelog

Big thanks to everyone for your support of Ultimate Foliage Renormalizer. Your reviews and feedback make it possible to keep adding new features!

1.5.5 — 2026-06-05

  • Fixed build errors

1.5.4

  • Added asmdefs

1.5.3

  • Actually fixed the bug I thought I fixed in 1.5.2

1.5.2

  • Fixed mesh maximum vertex count when renormalizing large polygon trees

1.5.1

  • Added clarification that impostors should not be renormalized, but rather created using a renormalized mesh

1.5.0

  • Added a button to update all dependent proxy stealers at once
  • Fixed a bug causing the Foliage Renormalizer Utility component to be set dirty every frame

1.4.0

  • Added a new "Mesh References" section to the Foliage Renormalizer Utility so you can quickly jump to mesh references in your assets folder

1.3.4

  • Fixed incorrect submesh selection during mesh generation when normal or vertex color debug is enabled
  • Fixed normal and vertex color debugs changing the displayed material override

1.3.3

  • Fixed the "Dependent Proxy Stealers" section not displaying when in Grass Mode

1.3.2

  • Fixed the "Don't ask again" review button
  • Fixed a CS0219 unused-variable warning in SDFProxyBuilder.cs

1.3.1

  • Fixed the Foliage Renormalizer Utility detecting skinned mesh renderers. This was unintended — proper Skinned Mesh Renderer support will come later.

1.3

  • Added the ability to revert the mesh of Proxy Stealers straight from the Foliage Renormalizer Utility component
  • Fixed an issue where "_Renormalized" would be appended to the renormalized mesh name multiple times

1.2

  • Added an option to save the output meshes to the same path as the source mesh

1.1

  • Added a new slider to control the influence strength of the output vertex normals
  • Greyed out Normal Transfer options when "Enable Normal Transfer" is unchecked
  • Greyed out AO baking options when "Enable SDF AO Baker" is unchecked
