Foliage Renormalizer Proxy Stealer

The Foliage Renormalizer Proxy Stealer is a companion component for foliage made of multiple renderers — separate trunk/leaf meshes, or several LOD levels. It lets a secondary renderer reuse the proxy mesh and generation settings of a main Foliage Renormalizer Utility, so every part of the plant shares consistent normals.

For the full workflow, see the Proxy Stealers guide.

Options

Option Description
Source The Foliage Renormalizer Utility component this stealer pulls its proxy mesh and settings from. Set automatically when added via the Utility's dependent buttons, or use Try to Auto Find source Renormalizer Utility / assign it manually.
Target Renderer The renderer that receives the renormalized mesh. Usually resolved automatically from the GameObject.
Material / Submesh Selector Configured from the source Utility's Override Proxy Stealer Material / Submesh Selector section — only needed for materials unique to the stealer.

Regenerating

After generating the main foliage mesh on the source Utility, regenerate each Proxy Stealer's mesh using its regenerate button. See Regenerating Proxy Stealer Meshes.
